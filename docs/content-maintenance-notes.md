## 01. Replace Hero Avatar Image

### Goal
Hero 영역의 `SK` placeholder를 실제 프로필 이미지로 교체한다.

### Image preparation
- Recommended size: 400 × 400 px
- Aspect ratio: 1:1 square
- Format: `.jpg` or `.png`
- Recommended filename: `avatar.jpg`
- Recommended file size: under 300KB if possible
